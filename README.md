## 📌 About Me

I build full-stack products on the **MERN stack**, from database schema to the last pixel of UI — and I care about getting the backend right, not just shipping a working demo. Lately that means writing APIs that don't fall over under real use and reading up on the security side most tutorials skip.

Three things I've shipped and actually use to learn from:
- **IntelliVerse** — hand it a spreadsheet, get back forecasts, anomalies, and root-cause analysis, no config
- **EcoFootprint** — scan a product, see its real environmental footprint, track your own
- **MindCare** — a mental wellness app people can actually open and use, not a portfolio mockup

I'm currently deepening my grip on distributed systems, secure API design, and the kind of system-design thinking that only shows up once an app has real users. If you're working on any of that, I'd like to compare notes.
